# Universal Marble Computer reference archive

Collected 2026-11-18. Official documents for investigating computation using stock VTech Marble Rush parts.

PDFs are retained in full; adjacent `.txt` files contain extracted searchable text. Diagrams must be read in the PDFs. This archive is not an exhaustive inventory of every regional set.

The Turing Tumble paper is the full 39-page arXiv version. Its educator-guide download is an excerpt ending at challenge 11. Research papers about railway circuits and reversible elements are background references, not evidence of VTech part behavior.
